# Tamsang POS (ตามสั่ง)

ระบบจัดการร้านอาหารตามสั่งครบวงจร (POS หน้าร้าน + ลูกค้าสแกนสั่งตามเลขโต๊ะ + จอคิวครัว KDS + คิดเงิน/PromptPay QR)

## ฟีเจอร์หลัก
- **หน้าร้าน & สั่งตามโต๊ะ (POS):** การ์ดเมนูอาหารตามสั่ง 12 รายการพร้อมรูปภาพอาหารจริง, ตัวกรองหมวดหมู่, ช่องทางทานที่ร้าน (โต๊ะ 1–8) / กลับบ้าน / เดลิเวอรี และเมนูจานด่วน 1 คลิก
- **Popup เลือกออปชัน (Dish Customizer):** เลือกเนื้อสัตว์, ราดข้าว/กับข้าว/ผัดเส้น, ขนาด (ธรรมดา/พิเศษ/จัมโบ้), ความเผ็ด 5 ระดับ, ไข่ดาว/ท็อปปิ้ง และคำขอพิเศษ
- **จอคิวครัว (KDS):** รวบเมนูซ้ำที่ผัดพร้อมกันได้และนับจำนวนไข่หน้าเตาอัตโนมัติ พร้อมบอร์ด 3 สถานะ (`รอคิวผัด` → `กำลังผัดไฟลุก` → `พร้อมเสิร์ฟ / เสิร์ฟแล้ว`)
- **คิดเงิน / เช็คบิล & PromptPay QR:** ออกใบเสร็จตามโต๊ะ, สร้าง QR PromptPay ตามมาตรฐาน EMVCo (CRC-16/CCITT-FALSE), คำนวณเงินทอนเงินสด และโหมดแยกจ่าย/หารค่าข้าวรายคน
- **QR สั่งอาหารประจำโต๊ะ:** สร้าง QR Code ประจำโต๊ะ 1–8 (`?table=X`) ให้ลูกค้าสแกนสั่งตรงเข้าคิวของโต๊ะนั้นทันที

## การติดตั้งและใช้งาน
```bash
# ติดตั้ง Dependencies
npm install

# รันโหมดพัฒนา (Dev Server)
npm run dev

# รัน Unit Tests
npm test

# Build สำหรับ Production
npm run build
```
